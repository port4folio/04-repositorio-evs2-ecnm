# Planificación Scrum del Proyecto

## Épicas

### Épica 1: Planificación del proyecto
Incluye la creación del proyecto Scrum, definición del backlog y organización de tareas.

### Épica 2: Integración con GitHub
Incluye la creación de ramas, commits, pull requests y consolidación de avances.

### Épica 3: Plan de aseguramiento de calidad
Incluye objetivos, roles, modelos de calidad, métricas y control de cambios.

## Sprint 1

### Objetivo del sprint
Configurar el entorno de trabajo y organizar la planificación inicial del proyecto.

### Tareas
- Crear proyecto Scrum en Jira.
- Definir product backlog.
- Crear épicas e historias de usuario.
- Crear repositorio en GitHub.
- Crear ramas por tarea.
- Realizar commits iniciales.

## Sprint 2

### Objetivo del sprint
Completar el plan de calidad y consolidar evidencias del trabajo realizado.

### Tareas
- Documentar modelos de calidad.
- Definir atributos de calidad.
- Crear métricas de evaluación.
- Definir proceso de control de cambios.
- Revisar pull requests.
- Consolidar informe final.
