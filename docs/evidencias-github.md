# Evidencias de Integración GitHub

## Repositorio del proyecto

El proyecto fue gestionado utilizando GitHub Classroom mediante un repositorio compartido por el equipo.

## Flujo de trabajo utilizado

El equipo trabajó utilizando ramas independientes para cada tarea asignada.

Cada integrante realizó:

- Creación de ramas.
- Commits individuales.
- Push al repositorio remoto.
- Pull requests para integración de cambios.

## Evidencias registradas

### Ramas creadas

- feature/configuracion-proyecto
- feature/objetivos-calidad
- feature/modelos-calidad
- feature/metricas-cambios

### Actividades realizadas

- Configuración inicial del proyecto.
- Creación de documentación base.
- Elaboración del plan de calidad.
- Planificación Scrum.
- Organización de tareas.

## Herramientas utilizadas

- GitHub Classroom
- GitHub
- Visual Studio Code
- Git
- Jira Scrum

## Beneficios obtenidos

- Mejor control de versiones.
- Organización del trabajo colaborativo.
- Seguimiento de cambios realizados.
- Integración ordenada mediante pull requests.
- Evidencia clara del trabajo individual del equipo.
